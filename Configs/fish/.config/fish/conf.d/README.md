# fish conf.d ordering

fish sources `conf.d/*.fish` by basename in ASCII order (digits < letters), then
`config.fish`. `config.fish` is deliberately empty — see its comment. Numeric
prefixes make the order explicit instead of leaving it to alphabetical accident.

Gaps of 5 or 10 leave room to insert without renumbering.

| Prefix | Contains | Why here |
|--------|----------|----------|
| `00_`  | kiro-cli `pre` shell integration | must be first; not renamed, see below |
| `05`   | env vars + PATH from `~/.config/environment.d` | foundation; `dotenv-apply` emits `set -gx PATH` (a wholesale replacement, not an append), so everything that adds to PATH must come after |
| `10`   | Go (`GOPATH`, `GOBIN`, PATH) | needs `XDG_*` from 05 |
| `15`   | Vite+ | prepends its own bin dir; must precede `zz-path-priority` |
| `20-25`| env-only snippets (pi, agent-browser, secrets) | no ordering needs, grouped |
| `30`   | pmg package-manager guard wrappers | functions, no PATH effect |
| `40-42`| abbreviations, aliases, kamal | interactive sugar |
| `50`   | venv auto-activate (`--on-variable PWD`) | |
| `60-62`| theme, key bindings | `62` holds user binds, after `61` |
| `70`   | Google Cloud SDK PATH | after 05, or the replacement erases it |
| `75`   | rbenv, tirith, atuin, zoxide, starship, intelli-shell | deliberately late: these bind keys, so they must run after `60-62` to win |
| `zz-`  | PATH priority fixup | see below |
| `99_`  | kiro-cli `post` shell integration | must be last; not renamed, see below |

## Files deliberately NOT renamed

`00_fig_pre.fish` and `99_fig_post.fish` are generated by `kiro-cli init`. A
rename does not stop `kiro-cli` from recreating the originals on its next
update, which would run the shell integration twice. Their existing names
already sort first and last, so renaming buys nothing. Leave them.

`zz-path-priority.fish` keeps a letter prefix on purpose. It must run after
*any* snippet that reorders PATH, including a `vite-plus.fish` that the Vite+
installer might recreate under its original letter-prefixed name. `zz-` sorts
after every letter; a numeric prefix would not.

## Regenerated-file caveat

`60-theme.fish` and `61-key-bindings.fish` were `fish_frozen_theme.fish` and
`fish_frozen_key_bindings.fish`, both written by fish 4.3's migration. Running
`fish_config` recreates `fish_frozen_theme.fish`. That is harmless — it sorts
after the numeric prefixes, so the newer file wins — but you will then have two
theme snippets and should delete `60-theme.fish`.
